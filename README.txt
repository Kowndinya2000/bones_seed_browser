BONES-SEED motion browser

Static GitHub Pages gallery of two selected dataset-reference animations.
index.html and style.css contain no external scripts, trackers, or credentials.
The public deployment contains rendered videos/posters only, not raw BVH/CSV
motion, full dataset metadata, or research implementation source.

Media is staged under /common/users/kb1204/boom_smp/benchmarks/data_scout/motion_browser_site,
following the project's artifact storage rules. Do not copy large media into
this lightweight source directory.
